# PokeIdle Central

Painel para o [PokeIdle](https://pokeidle.io/app) que funciona no computador e no celular.

- Visão geral de todas as suas contas, com o que precisa de atenção no topo
- Sugestão e troca automática de hunt por XP do treinador ou por ouro, com regras de segurança
- Reposição automática de pokébolas, poções e revives
- Venda automática de itens no mercado (só contas alternativas)
- Chances de shiny e custo por captura

## Instalação

Abra o link abaixo no aparelho, com o gerenciador de scripts já instalado, e confirme:

**https://raw.githubusercontent.com/marcoribeirogray/pokeidle-central/main/pokeidle-central.user.js**

| Aparelho | Navegador | Gerenciador |
|---|---|---|
| Computador (Windows, Mac, Linux) | Chrome, Edge ou Firefox | Tampermonkey ou Violentmonkey |
| Android | Firefox | Violentmonkey |
| Mac e iPhone | Safari | Userscripts (App Store, grátis) |

O Chrome do Android e os navegadores do iPhone que não são o Safari não aceitam scripts.

## Atualizações

O script se atualiza sozinho a partir deste repositório. A versão instalada aparece ao lado do nome do painel e, quando houver uma nova, surge o botão **Nova versão**. Em **Ajustes > Geral** dá para procurar atualização na hora.

## Privacidade

O script roda só no seu navegador. Nicks, configurações e históricos ficam guardados no seu aparelho e nunca são enviados para fora do jogo.
